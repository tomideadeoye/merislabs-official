## Usage Instructions

### Method 1: Use Image File (Recommended)
1. Download your preferred PNG image
2. Open your email client's signature settings
3. Insert the image directly

**Gmail:**
- Settings → See all settings → General → Signature
- Click "Insert image" icon and upload the PNG

**Outlook:**
- File → Options → Mail → Signatures
- Click "Insert Image" and select the PNG

### Method 2: Use HTML Version
1. Open `signature-v2-simple.html` in a browser
2. Copy the image
3. Paste into your email signature settings

### Method 3: Link to Image (For Advanced Users)
Use this HTML in your signature settings:
```html
<img src="https://merislabs-official.vercel.app/nicarb/christmas-signatures/nicarb_final_2026_white_1765805295269.png" alt="NICARB Christmas 2026" style="max-width: 600px; height: auto;">
```
