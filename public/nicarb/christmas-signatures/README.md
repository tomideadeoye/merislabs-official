## How to Use

1. Open the `.html` file in a text editor or browser
2. **Copy the HTML code** (not the whole page, just the HTML inside)
3. Paste directly into your email signature settings

### Gmail
- Settings → See all settings → General → Signature
- Paste the HTML in the signature box

### Outlook
- File → Options → Mail → Signatures
- Paste the HTML in the signature editor
